# GNS3 Image Manager

Удобный графический менеджер образов для GNS3 с интеграцией API.  
Позволяет просматривать, добавлять, удалять образы QEMU, создавать шаблоны виртуальных машин со всеми параметрами, а также автоматически очищать неиспользуемые файлы и «осиротевшие» шаблоны.

## Основные возможности

- 📁 **Просмотр образов** – таблица с файлами в папке `~/GNS3/images/QEMU`. Показывает имя, размер и дату изменения. Поддерживает сортировку по любому столбцу.
- ➕ **Добавление образов** – копирование выбранного файла в рабочую папку GNS3. Можно указать папку для импорта по умолчанию.
- ❌ **Удаление образов**
  - Выборочное удаление с автоматическим удалением связанных шаблонов и их узлов в проектах.
  - Удаление всех образов, которые не используются ни в одном шаблоне.
  - Удаление шаблонов, у которых отсутствует файл образа на диске.
- 🖥️ **Создание шаблонов QEMU через API** – заполнение всех параметров: имя, RAM, CPU, адаптеры, консоль, символ, категория, интерфейсы дисков, linked clone и другие. Имя шаблона автоматически формируется из имени файла.
- 🌐 **Интеграция с GNS3 API**
  - Проверка доступности сервера с индикатором (зелёная / красная точка).
  - Автоматическое открытие / закрытие проектов при удалении узлов.
- 🎨 **Тёмная тема** – комфортная работа в тёмных тонах.
- ⚙️ **Гибкие настройки** – все параметры по умолчанию сохраняются в `~/.gns3_image_manager_config.json` и могут быть изменены через графический интерфейс.
- 🧩 **Большой диалог выбора файлов** – удобная навигация по папкам с фильтрацией по расширениям образов.
